# Tank-draining data (not redistributed)

`analysis.py` reads three files from this folder. They come from the repository of
G. Fabusola & C. M. Simon (2025), *Chem. Eng. Sci.* 309, 121488, doi:10.1016/j.ces.2025.121488:
<https://github.com/SimonEnsemble/tank_inverse_problem> (folder `data/`):

- `liq_level_data_empty_train.csv`
- `liq_level_data_empty_test.csv`
- `level_sensor_calibration.csv`

The repository has no licence file, so the files are not copied into this paper's repository. Download them
into this folder before running `uv run python paper/analysis.py`.
